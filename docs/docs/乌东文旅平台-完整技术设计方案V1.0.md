### 1.2 模块边界与通信方式

**模块化设计原则：**
- 每个模块独立 Controller/Service/Entity
- 模块间通过公共服务层通信（不直接调用）
- 共享数据通过公共服务提供的接口访问

**通信关系：**
```
模块1(衣) ─┐
模块2(食) ─┤
模块3(住) ─┼──→ 公共服务层 ──→ 统一订单/支付/用户
模块4(行) ─┤
模块5(社区)─┘
模块6(管理)─→ 直接访问所有模块数据（只读/管理操作）
```

### 1.4 微信小程序发布流程

```
┌────────────────────────────────────────────────────────────┐
│            uni-app 小程序开发与发布流程                        │
└────────────────────────────────────────────────────────────┘

【开发阶段】
1. 本地开发
   └─> HBuilderX 或 VS Code
   └─> npm run dev:mp-weixin
   └─> 生成 /dist/dev/mp-weixin 目录

2. 微信开发者工具预览
   └─> 导入 /dist/dev/mp-weixin 目录
   └─> 填写 AppID (需先注册小程序)
   └─> 真机预览/调试

【发布阶段】
3. 构建生产版本
   └─> npm run build:mp-weixin
   └─> 生成 /dist/build/mp-weixin 目录

4. 上传代码
   └─> 微信开发者工具 → 上传
   └─> 填写版本号和备注
   └─> 上传到微信后台

5. 提交审核
   └─> 登录微信公众平台 (mp.weixin.qq.com)
   └─> 版本管理 → 开发版本 → 提交审核
   └─> 填写功能说明、测试账号
   └─> 等待审核 (通常1-7天)

6. 发布上线
   └─> 审核通过后 → 版本管理 → 发布
   └─> 用户即可在微信搜索使用

【环境配置】
┌─────────────────────────────────────────┐
│ 开发环境    → https://dev-api.wudong.com  │
│ 测试环境    → https://test-api.wudong.com │
│ 生产环境    → https://api.wudong.com      │
└─────────────────────────────────────────┘

【域名配置（必须）】
小程序后台 → 开发管理 → 开发设置 → 服务器域名
- request合法域名: https://api.wudong.com
- uploadFile合法域名: https://api.wudong.com
- downloadFile合法域名: https://api.wudong.com

【注意事项】
✓ 域名必须备案且配置HTTPS证书
✓ 个人主体小程序无法使用支付功能
✓ 建议注册企业主体小程序
✓ 首次发布需要填写《用户隐私保护指引》
```

## 第二部分：技术选型详解

### 2.1 后端技术栈

| 技术 | 版本 | 用途 | 选型理由 |
|-----|------|------|---------|
| **Node.js** | 18.x LTS | 运行时环境 | 长期支持版本，性能稳定 |
| **Midway.js** | 3.x | Web框架 | 阿里开源企业级框架，支持IoC/AOP/装饰器 |
| **TypeScript** | 5.x | 开发语言 | 类型安全，降低协作成本 |
| **TypeORM** | 0.3.x | ORM框架 | 支持MySQL，装饰器风格与Midway一致 |
| **MySQL** | 8.0.x | 关系数据库 | 主流选择，支持JSON字段，性能优秀 |
| **Redis** | 6.x | 缓存/会话 | 用于Session、热点数据缓存、消息队列 |
| **JWT** | jsonwebtoken | 身份认证 | 无状态认证，适合前后端分离 |
| **bcrypt** | 5.x | 密码加密 | 安全的哈希算法 |
| **multer** | 1.4.x | 文件上传 | Midway官方推荐 |
| **dayjs** | 1.11.x | 时间处理 | 轻量级，替代moment.js |
| **axios** | 1.x | HTTP客户端 | 用于对接微信支付等第三方API |
| **PM2** | 5.x | 进程管理 | 生产环境进程守护 |

### 2.2 前端技术栈

#### 小程序端 (uni-app)
| 技术 | 版本 | 用途 | 选型理由 |
|-----|------|------|---------|
| **uni-app** | 3.x | 跨端框架 | Vue3语法，一次开发多端发布 |
| **Vue** | 3.x | 前端框架 | Composition API，响应式系统 |

#### PC网页端 (Vue3)
| 技术 | 版本 | 用途 | 选型理由 |
|-----|------|------|---------|
| **Vue** | 3.x | 前端框架 | 与小程序统一技术栈 |
| **Element Plus** | 2.x | UI组件库 | Vue3生态最成熟的PC端组件库 |
| **Vue Router** | 4.x | 路由管理 | Vue3官方路由 |
| **Pinia** | 2.x | 状态管理 | 同小程序端 |

#### 管理后台 (Cool Admin)
| 技术 | 版本 | 用途 | 选型理由 |
|-----|------|------|---------|
| **Cool Admin** | 7.x | 后台框架 | 基于Vue3+Element Plus，内置RBAC权限 |
