# 第一部分：项目概述

## 项目简介

### 项目背景
乌东村是贵州黔东南苗族特色村寨，本项目旨在构建一站式数字化文旅服务平台，涵盖"衣食住行"全业务场景。

### 项目目标
- 为游客提供一站式线上服务（浏览、预订、支付、社区）
- 为商家提供完善的后台管理工具
- 为平台运营方提供数据分析和运营能力

### 三端范围
| 终端 | 技术栈 | 主要用户 |
|-----|--------|---------|
| 小程序端 | uni-app (Vue3) | 游客 |
| PC网页端 | Vue3 + Element Plus | 游客、商家 |
| 管理后台 | Cool Admin (Vue3) | 商家、管理员 |

---

## 技术架构

### 整体架构图

```
┌─────────────────────────────────────────┐
│         客户端层（三端）                   │
│  uni-app | Vue3 PC | Cool Admin         │
└──────────────┬──────────────────────────┘
               │ HTTPS/JSON
┌──────────────▼──────────────────────────┐
│      业务服务层（Midway.js 3.x）          │
│  6个业务模块 + 公共服务层                  │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│     数据层（MySQL 8.0 + Redis 6.x）      │
└─────────────────────────────────────────┘
```

### 技术栈

**后端**
- 框架：Midway.js 3.x + TypeScript 5.x
- 数据库：MySQL 8.0 + TypeORM 0.3.x
- 缓存：Redis 6.x
- 认证：JWT + bcrypt
- 进程管理：PM2

**前端**
- 小程序：uni-app 3.x (Vue3 + Pinia)
- PC端：Vue 3 + Element Plus + Vite
- 管理后台：Cool Admin 7.x
- 可视化：ECharts 5.x

**运维**
- Web服务器：Nginx
- 操作系统：Ubuntu 20.04
- 文件存储：本地磁盘

## 6个模块划分

### 模块分工表

| 小组 | 模块 | 业务范围 | 主要功能 |
|-----|------|---------|---------|
| **第1组** | 衣-非遗商品 | 商品电商 | 商品分类、SKU管理、购物车、订单、评价 |
| **第2组** | 食-餐饮美食 | 餐饮+特产 | 餐厅展示、餐位预订、农产品销售 |
| **第3组** | 住-住宿预订 | 民宿预订 | 民宿管理、房型房态、在线预订 |
| **第4组** | 行-线路订票 | 景区门票 | 门票销售、路线套餐、电子票核销 |
| **第5组** | 社区-照片分享 | UGC社区 | 游记发布、评论互动、话题关注 |
| **第6组** | 平台管理后台 | 全局管理 | 用户管理、数据统计、内容审核、财务结算 |

### 模块边界说明

**重要原则**：
1. ✅ 各模块功能**互不重叠**
2. ✅ 模块间通过**公共服务**通信（不直接调用）
3. ✅ 共享数据使用**统一接口**访问

**公共服务（所有模块共用）**：
- 用户认证服务（UserService）
- 统一订单服务（OrderService）
- 统一支付服务（PaymentService）
- 购物车服务（CartService）
- 文件上传服务（UploadService）
- 消息通知服务（MessageService）
- 搜索服务（SearchService）

## 快速开始

### 环境要求
- Node.js >= 18.x
- MySQL >= 8.0
- Redis >= 6.x
- Git

### 获取代码

```bash
# 克隆项目
git clone https://github.com/your-org/wudong-platform.git
cd wudong-platform
```

### 后端启动

```bash
cd backend

# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local，填入数据库配置

# 3. 初始化数据库
mysql -u root -p < ../database/init.sql

# 4. 启动开发服务器
npm run dev

# 访问 http://localhost:7001
# Swagger文档：http://localhost:7001/swagger-ui/index.html
```

```bash
cd frontend-pc

# 访问 http://localhost:5173
```

### 管理后台启动



3. **提交前自测**：确保代码能运行
4. **遇到冲突**：先与团队沟通，再解决冲突

# 第三部分：数据库设计

## 数据库整体设计

### 设计原则

1. **命名规范**
   - 表名：小写+下划线（如 `product`、`product_sku`）
   - 字段名：小写+下划线（如 `created_at`、`user_id`）
   - 主键：统一使用 `id`，自增INT
   - 时间戳：`created_at`、`updated_at`（自动维护）

2. **字段规范**
   - 价格：DECIMAL(10,2)
   - 状态：TINYINT（1启用 0禁用）
   - JSON字段：存储非结构化数据

3. **索引优化**
   - 高频查询字段添加索引
   - 外键添加索引
   - 组合索引遵循最左前缀原则

### 数据库清单

**总计约50张表，分为：**
- 公共表：10张（用户、订单、支付、购物车等）
- 模块1表：6张（商品相关）
- 模块2表：7张（餐饮相关）
- 模块3表：5张（住宿相关）
- 模块4表：7张（订票相关）
- 模块5表：7张（社区相关）
- 模块6表：8张（管理相关）

---

## 公共表结构

### 1. user（用户表）

```sql
CREATE TABLE `user` (
  `id` INT UNSIGNED AUTO_INCREMENT PRIMARY KEY COMMENT '用户ID',
  `phone` VARCHAR(11) NOT NULL UNIQUE COMMENT '手机号',
  `password` VARCHAR(255) NOT NULL COMMENT '密码（bcrypt加密）',
  `nickname` VARCHAR(50) DEFAULT '游客' COMMENT '昵称',
  `avatar` VARCHAR(500) DEFAULT NULL COMMENT '头像URL',
  `gender` TINYINT DEFAULT 0 COMMENT '性别：0未知 1男 2女',
  `role` TINYINT DEFAULT 1 COMMENT '角色：1游客 2商家 3管理员',
  `status` TINYINT DEFAULT 1 COMMENT '状态：1正常 0禁用',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX `idx_phone` (`phone`),
  INDEX `idx_role` (`role`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 2. order（订单主表）

```sql
CREATE TABLE `order` (
  `id` INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `order_no` VARCHAR(32) NOT NULL UNIQUE COMMENT '订单号',
  `user_id` INT UNSIGNED NOT NULL COMMENT '用户ID',
  `order_type` TINYINT NOT NULL COMMENT '订单类型：1商品 2餐位 3住宿 4门票 5路线',
  `module` VARCHAR(20) NOT NULL COMMENT '所属模块',
  `total_amount` DECIMAL(10,2) NOT NULL COMMENT '订单总额',
  `pay_amount` DECIMAL(10,2) NOT NULL COMMENT '实付金额',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1待支付 2已支付 3已完成 4已取消 5已退款',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX `idx_order_no` (`order_no`),
  INDEX `idx_user_id` (`user_id`),
  INDEX `idx_status` (`status`),
  CONSTRAINT `fk_order_user` FOREIGN KEY (`user_id`) REFERENCES `user`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单主表';
```

### 3. cart（购物车表）

```sql
CREATE TABLE `cart` (
  `id` INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `user_id` INT UNSIGNED NOT NULL COMMENT '用户ID',
  `product_id` INT UNSIGNED NOT NULL COMMENT '商品ID',
  `sku_id` INT UNSIGNED NOT NULL COMMENT 'SKU ID',
  `quantity` INT NOT NULL DEFAULT 1 COMMENT '数量',
  `checked` TINYINT DEFAULT 1 COMMENT '是否选中',
  `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_user_sku` (`user_id`, `sku_id`),
  CONSTRAINT `fk_cart_user` FOREIGN KEY (`user_id`) REFERENCES `user`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='购物车表';
```

### 后端开发流程

#### 1. 创建新接口

```typescript
// src/modules/product/controller/product.controller.ts

import { Controller, Get, Query } from '@midwayjs/core';
import { ProductService } from '../service/product.service';

@Controller('/api/product')
export class ProductController {
  
  @Inject()
  productService: ProductService;
  
  /**
   * GET /api/product/list - 商品列表
   */
  @Get('/list')
  async list(@Query() query: ProductQueryDto) {
    return await this.productService.list(query);
  }
}
```

#### 2. 编写Service

```typescript
// src/modules/product/service/product.service.ts

import { Provide } from '@midwayjs/core';
import { InjectEntityModel } from '@midwayjs/typeorm';
import { Repository } from 'typeorm';
import { Product } from '../entity/product.entity';

@Provide()
export class ProductService {
  
  @InjectEntityModel(Product)
  productRepo: Repository<Product>;
  
  async list(query: ProductQueryDto) {
    const qb = this.productRepo.createQueryBuilder('product');
    
    // 分类筛选
    if (query.categoryId) {
      qb.andWhere('product.categoryId = :categoryId', { 
        categoryId: query.categoryId 
      });
    }
    
    // 分页
    const skip = (query.page - 1) * query.pageSize;
    qb.skip(skip).take(query.pageSize);
    
    const [list, total] = await qb.getManyAndCount();
    
    return { list, total, page: query.page, pageSize: query.pageSize };
  }
}
```

### 常见联调问题

**问题1：跨域错误**
```
Access to XMLHttpRequest at 'http://localhost:7001/api/...' 
from origin 'http://localhost:5173' has been blocked by CORS policy
```

**解决方案**：
后端配置CORS中间件
```typescript
// src/configuration.ts
import * as cors from '@koa/cors';

export class MainConfiguration {
  async onReady() {
    this.app.use(cors({
      origin: '*',  // 开发环境允许所有域名
      credentials: true,
    }));
  }
}
```

**问题2：Token未携带**
```
401 Unauthorized
```

**解决方案**：
前端请求拦截器添加Token
```typescript
// src/utils/request.ts
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```

**问题3：数据格式不匹配**

**解决方案**：
- 前后端对照API文档
- 使用TypeScript类型定义
- 后端参数校验（使用DTO）
