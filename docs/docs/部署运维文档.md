## 服务器环境准备

### 1. 推荐配置

**单机部署（适合初期/教学环境）**
- CPU：4核
- 内存：8GB
- 硬盘：100GB SSD
- 操作系统：Ubuntu 20.04 LTS / CentOS 7

**生产环境（分布式部署）**
- 应用服务器：4核8GB × 2台
- 数据库服务器：8核16GB × 1台
- Redis服务器：2核4GB × 1台

### 2. 安装基础软件

```bash
# 更新系统
sudo apt-get update
sudo apt-get upgrade -y

# 安装Node.js 18.x
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node -v  # 应显示 v18.x.x
npm -v

# 安装MySQL 8.0
sudo apt-get install mysql-server-8.0 -y

# 安装Redis 6.x
sudo apt-get install redis-server -y

# 安装Nginx
sudo apt-get install nginx -y

# 安装PM2（全局）
sudo npm install -g pm2

# 安装Git
sudo apt-get install git -y
```

## 后端部署

### 1. 克隆代码

```bash
# 创建项目目录
sudo mkdir -p /var/www
cd /var/www

# 克隆代码
git clone https://github.com/your-org/wudong-backend.git
cd wudong-backend

# 安装依赖
npm install --production
```

### 2. 配置环境变量

```bash
# 创建生产环境配置
cp .env.example .env.production

# 编辑配置
vim .env.production
```

**.env.production 内容：**
```bash
NODE_ENV=production
PORT=7001

# 数据库
DB_HOST=localhost
DB_PORT=3306
DB_USERNAME=wudong_user
DB_PASSWORD=your_strong_password_here
DB_DATABASE=wudong_platform

# Redis
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=your_redis_password_here

# JWT
JWT_SECRET=your_jwt_secret_key_change_this
JWT_EXPIRES_IN=7200

# 文件上传
UPLOAD_DIR=/var/www/wudong-backend/uploads
MAX_FILE_SIZE=5242880

# 微信配置
WECHAT_APP_ID=your_wechat_app_id
WECHAT_APP_SECRET=your_wechat_app_secret
WECHAT_MCH_ID=your_wechat_mch_id
WECHAT_API_KEY=your_wechat_api_key

# 短信配置
SMS_PROVIDER=aliyun
SMS_ACCESS_KEY=your_aliyun_access_key
SMS_SECRET_KEY=your_aliyun_secret_key
```

### 3. 构建项目

```bash
# 构建TypeScript
npm run build

# 验证构建结果
ls dist/
```

### 4. PM2配置

**创建 ecosystem.config.js：**
```javascript
module.exports = {
  apps: [{
    name: 'wudong-api',
    script: './bootstrap.js',
    cwd: '/var/www/wudong-backend',
    instances: 2,  // 启动2个实例（集群模式）
    exec_mode: 'cluster',
    env: {
      NODE_ENV: 'development',
    },
    env_production: {
      NODE_ENV: 'production',
    },
    error_file: '/var/www/wudong-backend/logs/err.log',
    out_file: '/var/www/wudong-backend/logs/out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
    merge_logs: true,
    max_memory_restart: '500M',
    autorestart: true,
    watch: false,
  }],
};
```

### 5. 启动应用

```bash
# 启动PM2
pm2 start ecosystem.config.js --env production

# 查看状态
pm2 status

# 查看日志
pm2 logs wudong-api

# 设置开机自启
pm2 startup
pm2 save
```

### 6. 常用PM2命令

```bash
# 重启应用
pm2 restart wudong-api

# 停止应用
pm2 stop wudong-api

# 删除应用
pm2 delete wudong-api

# 查看监控
pm2 monit

# 查看详细信息
pm2 info wudong-api

# 重载日志
pm2 reloadLogs
```

## 数据库配置

### 1. 创建数据库用户

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE IF NOT EXISTS wudong_platform 
DEFAULT CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'wudong_user'@'localhost' IDENTIFIED BY 'your_strong_password_here';

-- 授权
GRANT ALL PRIVILEGES ON wudong_platform.* TO 'wudong_user'@'localhost';
FLUSH PRIVILEGES;

-- 退出
exit;
```

### 2. 导入数据库脚本

```bash
# 导入表结构
mysql -u wudong_user -p wudong_platform < database/schema.sql

# 导入初始数据
mysql -u wudong_user -p wudong_platform < database/data.sql
```

### 3. MySQL性能优化

**编辑 /etc/mysql/mysql.conf.d/mysqld.cnf：**
```ini
[mysqld]
# 基础配置
max_connections = 500
max_connect_errors = 100

# InnoDB配置
innodb_buffer_pool_size = 2G
innodb_log_file_size = 256M
innodb_flush_log_at_trx_commit = 2
innodb_flush_method = O_DIRECT

# 查询缓存
query_cache_type = 1
query_cache_size = 64M

# 慢查询日志
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
```

```bash
# 重启MySQL
sudo systemctl restart mysql
```

### 4. Redis配置

**编辑 /etc/redis/redis.conf：**
```ini
# 绑定地址
bind 127.0.0.1

# 端口
port 6379

# 密码
requirepass your_redis_password_here

# 最大内存
maxmemory 1gb
maxmemory-policy allkeys-lru

# 持久化
save 900 1
save 300 10
save 60 10000
```

```bash
# 重启Redis
sudo systemctl restart redis
```

## Nginx配置

### 1. 主配置文件

**创建 /etc/nginx/sites-available/wudong：**
```nginx
# API服务器upstream
upstream api_backend {
    server 127.0.0.1:7001 weight=1 max_fails=3 fail_timeout=30s;
    keepalive 32;
}

# PC端 - www.wudong.com
server {
    listen 80;
    server_name www.wudong.com wudong.com;
    
    # 重定向到HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name www.wudong.com wudong.com;
    
    # SSL证书配置
    ssl_certificate /etc/ssl/certs/wudong.crt;
    ssl_certificate_key /etc/ssl/private/wudong.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    
    # 根目录
    root /var/www/wudong-pc;
    index index.html;
    
    # Gzip压缩
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/json;
    
    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API代理
    location /api {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
    
    # 静态资源
    location /uploads {
        alias /var/www/wudong-backend/uploads;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # 日志
    access_log /var/log/nginx/wudong-pc-access.log;
    error_log /var/log/nginx/wudong-pc-error.log;
}

# 管理后台 - admin.wudong.com
server {
    listen 80;
    server_name admin.wudong.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name admin.wudong.com;
    
    ssl_certificate /etc/ssl/certs/wudong.crt;
    ssl_certificate_key /etc/ssl/private/wudong.key;
    
    root /var/www/wudong-admin;
    index index.html;
    
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api {
        proxy_pass http://api_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
    
    access_log /var/log/nginx/wudong-admin-access.log;
    error_log /var/log/nginx/wudong-admin-error.log;
}

# API服务 - api.wudong.com
server {
    listen 443 ssl http2;
    server_name api.wudong.com;
    
    ssl_certificate /etc/ssl/certs/wudong.crt;
    ssl_certificate_key /etc/ssl/private/wudong.key;
    
    # 限流配置
    limit_req_zone $binary_remote_addr zone=api_limit:10m rate=100r/s;
    limit_req zone=api_limit burst=200 nodelay;
    
    location / {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
    
    access_log /var/log/nginx/wudong-api-access.log;
    error_log /var/log/nginx/wudong-api-error.log;
}
```

### 2. 启用配置

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/wudong /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重载配置
sudo systemctl reload nginx

# 查看状态
sudo systemctl status nginx
```

### 3. SSL证书配置

**使用Let's Encrypt免费证书：**
```bash

# 申请证书

```

    daily
    rotate 30
    missingok
    notifempty
    compress
    delaycompress
    sharedscripts
    postrotate
        nginx -s reopen
    endscript
}

## 常见问题

### 1. 数据库连接失败

**问题**：应用启动报 `ECONNREFUSED` 错误

**解决**：
```bash
# 检查MySQL是否运行
sudo systemctl status mysql

# 检查端口是否开放
netstat -tlnp | grep 3306

# 检查用户权限
mysql -u wudong_user -p
SHOW GRANTS;
```

### 2. PM2应用频繁重启

**问题**：PM2日志显示 `errored` 状态

**解决**：
```bash
# 查看错误日志
pm2 logs wudong-api --err

# 检查内存使用
pm2 info wudong-api

# 增加内存限制
pm2 restart wudong-api --max-memory-restart 1G
```

### 3. Nginx 502 Bad Gateway

**问题**：访问网站返回502错误

**解决**：
```bash
# 检查后端服务是否运行
pm2 status

# 检查端口是否监听
netstat -tlnp | grep 7001

# 查看Nginx错误日志
tail -f /var/log/nginx/error.log

# 重启服务
pm2 restart wudong-api
sudo systemctl restart nginx
```

### 4. 小程序无法连接API

**问题**：小程序报 `request:fail`

**解决**：
1. 检查域名是否在小程序后台配置
2. 确保域名已备案且配置HTTPS
3. 检查服务器防火墙规则
4. 测试API接口是否正常

```bash
# 测试API
curl https://api.wudong.com/api/health
```

## 备份策略

### 1. 数据库备份

```bash
# 创建备份脚本 /opt/scripts/backup-mysql.sh
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/var/backups/mysql"
DB_NAME="wudong_platform"
DB_USER="wudong_user"
DB_PASS="your_password"

mkdir -p $BACKUP_DIR

mysqldump -u$DB_USER -p$DB_PASS $DB_NAME | gzip > $BACKUP_DIR/${DB_NAME}_${DATE}.sql.gz

# 删除30天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete

# 添加定时任务
# 0 2 * * * /opt/scripts/backup-mysql.sh
```

### 2. 代码备份

```bash
# 备份uploads目录
rsync -avz /var/www/wudong-backend/uploads/ /var/backups/uploads/

# 备份到远程服务器
rsync -avz -e ssh /var/www/wudong-backend/ user@backup-server:/backups/wudong/
```
